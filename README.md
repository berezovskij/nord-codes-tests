# nord-codes-tests

API-тесты на Java 17, JUnit 5 и WireMock. Отчёт — Allure.
Приложение, тесты и генератор отчёта выполняются в Docker.

## Требования

- Docker Desktop с запущенным Docker Engine и Docker Compose v2.
- Образы рассчитаны на Linux/ARM64, в том числе Mac с Apple Silicon.
- Shell (`sh`) и стандартные утилиты macOS для скрипта запуска и сбора логов.
- Интернет для первоначального скачивания образов и зависимостей.
  После подготовки образов прогон работает без интернета.

## Подготовка перед первым запуском

Откройте Docker Desktop. Все команды ниже выполняются из корня проекта.
Скачайте образ WireMock и соберите образы приложения и тестового раннера:

```sh
docker compose --env-file /dev/null --file compose.yaml --profile tests pull --policy always wiremock
docker compose --env-file /dev/null --file compose.yaml --profile tests build app runner
```

На этом этапе контейнеры ещё не запускаются. Подготовка нужна перед первым
прогоном; после изменения тестов или конфигурации образов повторите сборку.
Во время подготовки приложение и тесты должны быть остановлены.
Параметр `--env-file /dev/null` отключает автозагрузку локального `.env`.

## Запуск тестов и генерация отчёта

После подготовки образов для каждого прогона достаточно одной команды:

```sh
sh docker/run-tests.sh
```

Скрипт сам создаёт и запускает контейнеры приложения, WireMock и тестового
раннера из готовых образов, выполняет тесты и генерирует автономный HTML-отчёт Allure.
Образы при этом не собираются и не скачиваются. Результаты сохраняются в проекте,
затем контейнеры останавливаются и удаляются.

- `reports/allure/index.html` — отчёт последнего прогона с успешной генерацией и экспортом HTML.
- `artifacts/run-XXXXXXXX/` — результаты конкретного прогона, логи и XML/TXT Surefire.

Отчёт генерируется и при падении тестов; скрипт при этом возвращает ненулевой код.
При ошибке генерации или экспорта прежний отчёт сохраняется.

Открыть отчёт на macOS:

```sh
open reports/allure/index.html
```

## Пример отчёта и найденные баги

В репозиторий приложен [пример Allure-отчёта](reports/allure/index.html):
19 тестов, 17 прошли, 2 выявили баги приложения:

1. LOGIN отклоняет допустимый по заданию token с буквой G.
2. При отказе авторизации в лог попадают переданный и настроенный API-ключи.
